# kimitoboku.github.io

## Development

### Prerequisites

- Docker
- Docker Compose

### Build and Run

```bash
# Start development server
docker compose up

# Run in background
docker compose up -d

# Stop server
docker compose down
```

The site will be available at http://localhost:4000

Live reload is enabled - changes will automatically refresh the browser.

Each post is also published as its raw Markdown source by appending `.md` to
the post URL. For example:

```text
/archive/2026/01/01/best-movie.md
```

This endpoint is generated by `_scripts/generate_raw_posts.rb`. Production
deployment therefore uses the custom GitHub Pages workflow in
`.github/workflows/pages.yml`.

### Rebuild

```bash
# Rebuild after Gemfile changes
docker compose build --no-cache

# Rebuild and start
docker compose up --build
```
